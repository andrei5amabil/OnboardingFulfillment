# POL-OFF: Offboarding Compliance & Data Retention Guidelines

## 1. Purpose & Scope
This policy establishes the mandatory execution order for departing personnel to eliminate security vulnerabilities and eliminate orphaned accounts[cite: 10].

## 2. Immediate Credential & Session Revocation
- **[POL-OFF-201] Deterministic Session Termination:** The execution engine must immediately disable directory login credentials, active bearer tokens, and open sessions on the termination date[cite: 10].
- **[POL-OFF-202] Entitlement Stripping:** All assigned SaaS seats, group memberships, and access scopes must be revoked to return licenses to available inventory pools[cite: 10].

## 3. Resource Transfer & Retention Buffers
- **[POL-OFF-301] Work Continuity Handover:** Active tickets, storage drives, and repository ownership must be systematically transferred to the designated manager or replacement[cite: 10].
- **[POL-OFF-302] Hardware Recovery Tasks:** Automated workflows must dispatch return waybills and instructions for all physical equipment assigned to the employee[cite: 10].
- **[POL-OFF-303] 90-Day Retention Hold:** Deactivated accounts must remain in a suspended, non-interactive state for 90 days before irreversible cryptographic purging[cite: 10].

## 4. Verification & Audit Sign-Off
- **[POL-OFF-401] Zero Residual Access Verification:** The runner must execute a multi-system audit confirming zero active entitlements[cite: 10]. Any detected residual access pauses the workflow and alerts IT[cite: 10].
- **[POL-OFF-402] Compliance Report Generation:** The final compliance report and audit entry are generated only after zero residual access is verified[cite: 10].
